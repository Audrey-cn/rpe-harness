## 1.0 实现

新增执行器、独立验证器、SQLite RunStore、统一 runtime、JSON CLI、旁路事件入口和发布验证脚本。默认安装带两个内置执行技能；源码外的 data 不再是运行前提。显式加载本地索引时共81个条目，其中两个内置条目可执行，其余只供能力推荐。

运行顺序：事件持久化 → 校验与环境探测 → 路由 → 白名单执行 → 独立验证暂存产物 → 无覆盖发布与目录同步 → 提交成功记录。成功必须同时有验证、产物hash和数据库终态，不能由LLM自报或文件存在推断。

事件幂等键为 `(source,event_id)`。并发重放返回同一run；未完成任务退出码3，拒绝2，执行失败/中断1，执行成功0；历史查询成功返回0。外部 `/usage` 与内部 verified_success_count 分开统计。

进程租约使用POSIX文件锁，避免PID复用误判。崩溃后的不完整记录标 interrupted；发布后提交前崩溃也不补记成功，steps保留发布意图和验证hash。需要重试时用新event_id和新输出；自动重新验证恢复留给后续版本。

## 文件边界

CSV保留第一条完整记录及顺序；支持中文、引号、多行字段、前导零。关键列必须明确，空关键列与缺列拒绝，既有输出及broken symlink拒绝覆盖。

XLSX清空重复行的值、评论与链接，保留行坐标，因而可能留空行。保留记录的公式文本、坐标和受支持样式不变。引用被清空行的公式、跨表/命名/动态引用、数组/复杂工作簿对象、富文本等明确拒绝。验证器重新读源与产物，还检查其他工作表。openpyxl不计算公式，未验证公式计算值。

1.0 面向macOS/Linux；Windows与任意复杂Excel文件未验证。SIGKILL可能留下暂存文件，不能按宽泛通配符自动删除用户文件。开发测试中的此类文件均位于自有临时目录并纳入最终清理。
