# 1.7 实测证据

failed-pilot保存初次真实G0超时的完整精简记录，后续补验不替换它。原始会话历史、工具全文、凭据及私密路径不导出。脱敏记录包含原文件digest与清理前已复核的seal，脱敏后的内容不是原seal的重新验证材料；另以导出manifest和Git版本绑定。公开输入和模型生成代码原字节分别保存。

`interrupted-pilot`保留中断预约，`failed-producer-pilot`保留后续超时；`generation-calibration`保留写出程序但原评分未关联的校准。`comparison`是完整48次正式实验及实际维护；`binding-supplement`是另外登记的6次已知输入补验，不重评原成绩。独立审计及整轮成本位于本目录，原始生成程序和公开产物有字节摘要，`reviews`保留审查结论。`runner-source`仅供复核本轮薄控制器，其中`.sha256`指清理前原始源，路径替换规则同上。

主实验学习组14次完整直接复用，原生/内置/学习分别16、14、15个正确产物；补验4/6。总token只能确认下界2,437,543。闭环成立与质量、成本或无人值守收益分开，完整边界见上级验收报告。
