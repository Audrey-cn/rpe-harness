RPE_AUDIT_DIR=$(mktemp -d /tmp/rpe-recheck.XXXXXX)
mkdir "$RPE_AUDIT_DIR/snapshot"
cp -R src tests data pyproject.toml README.md "$RPE_AUDIT_DIR/snapshot/"
cp reports/audit-2026-10-13/evidence/run_audit.py "$RPE_AUDIT_DIR/run_audit.py"
PYTHONDONTWRITEBYTECODE=1 python "$RPE_AUDIT_DIR/run_audit.py"
~~~

运行器使用其旁边的 snapshot 和输出目录，输出新的 JSON 和日志。commands.json 记录原本那一次实验的临时路径，这些路径是历史运行位置；本目录中的同名证据文件才是本次交付后的持久入口。run_audit.py 包含手工探针，不是项目正式测试套件；正式测试以 pytest.log/pytest.xml 为准。

wheel 验证在独立源码副本中执行 python -m build --wheel --no-isolation，再解包到另一个临时目录，在不含 src 的环境中导入 rpe_harness.server。build_results.json 保存构建命令、wheel成员与载入后的状态。当前 wheel 只包含代码，独立运行时没有配置技能索引；这项结果与开发目录直接导入不同。

性能结果受机器、Python版本、进程状态和任务合成方式影响。消融与中文改写只对当前生成任务和所列探针成立；它们不能替代真实 Hermes 用户任务对照。
