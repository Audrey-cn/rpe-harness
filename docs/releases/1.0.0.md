# 1.0.0

首个可验证本地执行版本：CSV/XLSX明确关键列首条去重，独立文件验证、无覆盖发布、SQLite事件与运行记录、幂等重放、进程租约恢复、JSON CLI、HTTP和Hermes旁路协议。

修复原型的UNKNOWN误选、格式/能力/事实绕过、来源丢失、内存反馈丢失、安装包缺运行能力、慢请求阻塞与文档入口失效。

支持macOS/Linux、Python>=3.10、openpyxl 3.1.x。XLSX保留行位置并清空重复记录，可能留空行；公式只验证结构，复杂对象和富文本拒绝。真实Hermes宿主插件、任意技能执行、自动LLM升级、自动持续学习与Consolidator尚未包含。

详见 [开发与验收报告](../../reports/v1.0.0/1.0开发与验收报告.md) 和 [README](../../README.md)。
