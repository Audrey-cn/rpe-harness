# RPE 1.7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Goal:** 真实任务反馈驱动工具生成，经独立验收在未见输入复用，诚实衡量质量和全量成本并完成清理。
**Architecture:** 训练材料导出、生成器和实验账本分开；复用已有CSV候选执行/验收/激活权威。Hermes为真实模型宿主，不引入新的常驻服务。
**Tech Stack:** Python>=3.10，唯一运行依赖openpyxl>=3.1.5,<3.2，SQLite，macOS隔离CLI。
**Spec:** docs/superpowers/specs/2026-10-14-rpe-v17-design.md

## Global Constraints

- 基线56b4451；代码位于本轮原生管理工作树，测试在独立owned-root。
- 不改日常Hermes/旧仓/全局Agent配置，不推送，不启动后台服务。
- 最多8训练导出，单输入/结果16KiB，总packet64KiB，候选64KiB；每次生成<=180秒，反馈后最多3次。
- 6训练、独立13例资格验收、8未见输入×2重复×3臂；冻结后不换代码。
- 未知总量保留null与已知下界；回退与候选直接成功分开。

## Review Focus

- 训练来源被改写或引用别的owned-root：生成前后拒绝，不漂移锚。
- 路径/凭据/未见输入泄漏：只导出白名单授权材料，生成器隔离。
- 模型超时且usage缺失：reservation/失败/下界保留，不能默认为零。
- 原生正确产物但调用关联不足：业务正确与流程证据分开计。
- 已冻结候选失败/回退：保留原评分与原版本，另登记补验。
