# RPE-Harness 1.0 Implementation Plan

> For agentic workers: use test-driven development for behavior and verification-before-completion for release. Independent file scopes are assigned below; do not edit another worker's files.

**Goal:** 交付可安装、可执行、可验证、可重启查询的本地基础版本。

**Architecture:** MCSI/Router → whitelisted executor → independent verifier → exclusive publish → SQLite result; CLI and HTTP share one runtime.

**Tech Stack:** Python >=3.10, stdlib, openpyxl 3.1.x, pytest, SQLite.

**Spec:** [设计](../specs/2026-10-13-rpe-v1-design.md)

**Global Constraints:** 不修改 Hermes 核心或用户配置；不覆盖原文件与既有输出；不删除用户共享历史；临时状态全放自有 /tmp 目录；stdout JSON；未知需求拒绝执行；不宣称未验证的学习收益。

**Review Focus:** 硬条件过滤、公式与记录语义、验证独立性、持久化幂等和并发、崩溃状态、安装包资源、清理归属。
